# HeinOnline: the owner's list (Photius lane 7a)

HeinOnline User Rules (help.heinonline.com/kb/heinonline-user-rules), as the owner read them on 2026-11-06:
saving and printing parts of the resource for education, research and private study is permitted; systematic
downloading "to stock or replace print holdings of a whole journal issue or book" is not; text and data mining is not;
distribution beyond authorized users is not; Hein enforces a 200-page limit per download. The owner decides how much
of the title to save with this text in front of him. No script, worker, fetcher or browser automation touches
heinonline.org; nothing saved from Hein is placed in the public repository (bytes stay in research/owner-inbox/hein/,
git-ignored); only hashes, page references and extracted facts go public. A Hein-dependent closure is never described
as public-domain custody; that label belongs to NARA M1118.

Residual numbered orders 1-7315 with no official witness and no checked replica, after the Photius merges: **2370** (file: `research/photius/HEIN_BLOCKS.csv`, one row per order with volume, block, page id and URL).

Smallest block set covering them: **86 blocks**, covering **2338** residual orders, with **1969** non-residual orders riding along. A block longer than 200 pages (vol. 5 "2979-A-3017" is 237) exceeds Hein's download limit and must be saved as two page ranges.

Two ways to proceed, both by hand in your own browser, one block at a time:

1. Save the block's PDF (click the block's PDF icon) into `research/owner-inbox/hein/<volume>-<block>.pdf`. The session hashes it, splits it, reads the text layer, aligns the tags and registers each order as `microfilm_witness` with bytes held privately (R38).
2. Or view pages and record facts in `research/owner-inbox/hein-checks.csv` with columns number, date, signatory, first_words, last_words, page_id. R38 treats those as page-check facts, never as held bytes.
