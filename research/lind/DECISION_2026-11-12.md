## 3. Decision rules (the smallest measurements that could change the choice)

1. **Triage keeps yield prospectively.** This needs no new spending: it is the first production that would run anyway.
   - Draw the first two batches at random from the 3,076 admitted orders (25 each, Papinian's batch size).
   - If 3 or more of the 50 reach ready, continue with A.
   - If 0 of the first 25, or 1 or fewer of 50, stop and diagnose before more spending. P(1 or fewer of 50) is 0.003
     at 15.5% and about 0.40 at 4%.
2. **Coordination stays lean.** Measured by `bentham.py usage` after batch 1.
   - If coordinator dollars are $0.15 or less per attempt, continue.
   - If above $0.25, stop and restructure before batch 2.
3. **Soft gates lose yield** (A-20261110-larrey-soft-probe, about $15-20). Deferred: it decides whether 2,073 hard-pass
   but soft-failing orders join the pool, which matters only after the admitted pool is mostly worked.
   - If 3 or more of 30 reach ready, relax the soft gate.
   - If 1 or fewer, keep it.
4. **The next lever after A+B is review.** Review is about 67% of per-ready cost under A+B.
   - Smallest test: blind re-review of the 24 existing undecided submissions (17 Papinian, 7 Haloander; outcomes
     known, including the 9 ready and the rejected ones) by a cheaper second-arm model. Keep one current arm. Cap $25.
   - If it reproduces every uphold and reject and catches every control, run a paired live comparison on new
     batches, keeping two independent arms.
   - If it disagrees on 2 or more, keep the current arms.
   - Agreement is not a real error rate: that needs the human certification sample.

## 5. Recommendation

**Strongest next intervention: A + B.** Enforce Larrey triage and run undecided production only under lean
coordination.

**Why it beats the alternatives:** the same expected ready count, about 477 (258-830), at about $2,800 instead of
about $6,700 to $7,000. It costs $0 cash, it is reversible, and it keeps the endpoint and both independent review arms
unchanged. C has a worse marginal cost now.

**What would reverse it:**
- decision rule 1 failing (triage does not separate prospectively);
- a kit change that narrows a basis or original rule without the gates following, caught by re-running this check
  after each claim-kit merge;
- the soft probe finding that soft gates drop real successes;
- coordination unable to stay lean at scale.

**Smallest next executable action:** merge this PR. That enforces triage, and Bentham re-plans on its next run. The
first production batch then is decision rule 1's measurement, run under an Augur plan.

**Measured savings so far:** none realised. The back-test is a retrospective counterfactual on 120 past attempts (62
failures avoidable, 0 successes lost). Every population figure above is a projection.
