## Method decided (from owner rulings + assembler code)
- First end = earliest of: an own fixed-date sunset (including as amended), or an express revocation that names the order/parent. Report deadlines and report-relative sunsets ("terminate N days after report", "upon final report") are NOT ends (ruling 2026-10-21 report-deadline); they are disclosed as spent facts. No packet has FACT evidence and report cover-page TERM records carry no date, so report/standstill dates cannot be later_events; say so in the rationale.
- Revocation that does not name the order by number (e.g. "as amended" parent revocation, or a wholesale parent revocation for an amending order) is disclosed as unnamed (ruling 2026-10-21 unnamed-instruments).
- Amendments are later_events with before/after text (strike-and-insert ruling). Whole_order_end = max clause first_end (assembler computes).
- Prefer plain fr-originals ACT ids (no grade, no working_text needed). EO 12319 ACTs exist only as APP mirror (node 247259; MIRROR_DOCUMENTS row sha a4521238..., heading/date/text_sha agree) so those need working_text confirmation; ACTOR_TEXT:EO:12319 is a whole FR issue (22K chars).
- Quote only exact substrings of the cited bytes (fr-originals OCR has spacing errors like "Em ergency"); quote short clean fragments and verify programmatically.
- Seven different ORIGINAL texts are clipped by my earlier dumps only; full files are fine (e.g. EO 12202 full text ends "1-402. ... terminate on September 30,1980.").
