# Executable excavator extension: evidence, decisions and measured cost

The reusable batch and undecided-overlay paths work. The matched experiment
**does not demonstrate lower total producer-plus-reviewer cost**. Packaging
reduced producer time and output, but independent review, new contrary-source
research and corrections consumed the gain. This is a retained negative result,
not a token-saving claim based on smaller files.

## Delivered execution path

`jobs/claim-kit/BATCH.md` documents executable `prepare → view → apply →
batch-check` commands. Prepare freezes1–50 complete dossier values, one source
catalogue, exact shared text spans, warnings/missing/overflow pointers, explicit
shared tasks and blank producer rows. Apply feeds explicit order/clause rows,
inventory corrections and unresolved outcomes through the existing assembler.
Batch-check runs exact dossier gates and the actual claim-checker, prints counts
and actionable failures, and retains the full audit. Decision edits use the same
packet/source hashes with zero extraction calls. Common rationale can be reused,
but every member has explicit earlier-end, scope, independent-command and
savings checks. Neither grouping nor producer approval grants legal status.

Existing claims and frozen Sol proposals retain their owners. `next` uses real
actor/provision/source/exception patterns; generic condition/report buckets are
excluded. Replacement proposals require an explicit flag and owner review;
reservations and other agents' claims/notes are preserved.

`overlay-prepare → overlay-review-sheet → overlay-propose` turns an independently
reviewed status-research decision into a versioned proposal, full experimental
dossier and blank lifecycle decision. `overlay-assemble` / `overlay-check` use
the existing assembler and retain the experimental label. No authoritative
write path exists. The concrete EO11352 provisional-NO proposal is independently
reviewed and ready for owner consideration, fingerprint
`210b5afb660d3a5b97fdd3dacb2b4c3d77187946dad84cb13de93be97ef0e771`.
Owner acceptance remains false; first-effective cessation, accrued effects,
earlier statutory changes and whole-lifecycle/cutoff questions remain explicit
gaps. EO4314 and EO12331 preserve difficult undecided handoffs.

Overlay freezes read compiled evidence once. Tested decision edits and runner
receipt-only changes reuse it without reading any compiled JSONL shard or
rebuilding. Changed code, consumed manifests, source bytes, history or authority
fail closed. Actual EO11352 validation confirms the same proposal fingerprint.

The runner records input Git identities/dirty hashes and verifies them before
the first publication attempt and after rejected pushes. Dynamic claim-kit data
and output reads have explicit input declarations. Each consumer retains the
actual prior-produced or later-producer base generation it consumed. Concurrent
newer input/output advances still reject. @Astra's ownership handoff is in the
runner report and Codex HANDOFF; older already-running publication scripts were
completed before this deployment.
