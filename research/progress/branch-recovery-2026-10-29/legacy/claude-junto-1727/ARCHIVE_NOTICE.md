These are exact historical Git blobs recovered for preservation. No contained program was run, and no acquisition, experiment, ledger entry, source grade, legal finding, canonical claim, readiness result or certification is activated or approved by this copy.

Claims, reviews, outcomes, cost statements and proposed contracts retain their historical context and require current independent validation before reuse. REPORT.md originals are stored as REPORT.historical.md; source paths and exact hashes are recorded in ../MANIFEST.json.

Scripts are stored with ordinary non-executable file permissions. Do not schedule or run them from this archive. PDF files labeled as Git LFS pointers contain pointers only; no PDF download or authentication is inferred. No message or archival request was sent.
