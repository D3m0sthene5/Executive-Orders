# Workflow map (Minard): the named jobs, placed by purpose

The dashboard's **Workflow** tab (hash `#workflow`) shows how the project's named jobs, past research
campaigns, agent review procedure and human gates move an executive order from "we learn it exists" to "a
complete dossier ready for human review". Named Minard, after Charles Joseph Minard, whose 1869 flow map of
Napoleon's march is the classic picture of a process.

It is a map of purpose, not a schedule or an automation chain: orders loop back (review rejects, missing
sources become fetch requests, tracker blockers and audit holds reopen steps), and **ready for human review is
not human certification** (certified: 0).

## Files

| File | What it is |

## Rules the data follows

- **Stats:** catalog figures are not copied here. The page joins each node's `catalog_tool` to the live `tools`
  dataset (`snapshots/<date>/TOOLS.csv`), so a catalog refresh updates them. All 43 catalog rows map to a node
  (the builder refuses a name that is not a catalog row). Figures from different tools overlap and are never added.
- **Ready count** on the Human review gate is read live from the `mission_log` dataset (the tracker's own count).
- **Status:** current = code that runs now; historical = every past agent campaign and stopped line, whatever its
  old catalog label said; proposed = never built.
- **Kinds:** named software; past research campaign; agent review procedure (independent AI review with planted
  controls, not a human gate); human or owner gate; proposal.
- **Namesakes:** only what the project recorded, with where. `documented` = in the repository; `recovered` = from
  the original naming conversation (NORTON); `inferred` = the project never recorded it and the map says so (Lamm);
  `none` = a descriptive name. Every Wikipedia link was resolved through Wikipedia's API (`provenance/wiki_cache.json`),
  and Codex independently opened the nine titles that were rate-limited at first (Domesday Book, Pinakes,
  Shepard's Citations, Last Spike (Canadian Pacific Railway), Pullman Strike, Digest (Roman law), Margaret Cross
  Norton, Junto (club), Capsule communicator, which redirects to Flight controller). The Rattle Watch has no article,
  so it has no link.
  - **NORTON:** Margaret Cross Norton, the Illinois State Archivist who stressed governmental provenance and
    department and function histories. Named by Astra on 2026-10-20 (reply of 15:02:16 UTC), recovered through the
    owner's Personal Context by Codex; source https://www.ilsos.gov/departments/archives/nortonbio.html.
  - **Lamm:** inferred, not recorded: the line handled orders that end by their own fixed term or sunset date, and
    Governor Richard Lamm signed Colorado's sunset law in April 1976 (Denver Public Library index,
    https://digital.denverlibrary.org/nodes/view/1663471).
  - **Cruden:** Alexander Cruden, `research/excavator/claude-nira-sweep-2026-10-29/cruden.py` lines 1-3.

## Refresh

1. Edit `WORKFLOW_NODES.json` (or rerun `provenance/merge.py` after editing a group file or `overrides.json`).
2. `python3 -X utf8 build_workflow_nodes.py` (add `--check-wikipedia` when links change; it is rate-limited).
3. Upload `workflow/WORKFLOW_NODES.csv` to the dashboard and point the `workflow_nodes` dataset at it.
   A catalog-only refresh needs none of this: the page reads the live `tools` dataset.
