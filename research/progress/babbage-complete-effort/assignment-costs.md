The missing original-source hash or uniquely located attributed current legal-text slice was already visible in assigned dossiers. This supports a causal hypothesis that deterministic prelaunch routing can remove a whole source-blocked assignment. It does not support a claim that question-centered research would remove 30 duplicated substantive investigations: this worker already shared the diagnosis.

The next smallest decisive observation is to run the existing dispatch/preflight route against those exact inputs and expose a current-predicate readiness condition. Compare the same endpoint, a pinned evidence-backed source hold with the same outstanding work, and include gate-review/correction costs. For full dossiers, follow both arms after the same sources arrive; a skipped launch alone cannot establish cheaper completed dossiers.

**Competent current-practice baseline:** current dispatch deliberately treats unselected actor/current-law leads as optional, checks their custody, and exposes optional-source gaps in its compact summary. The protocol separately requires a current legal predicate for a YES claim. A fair new comparison must give the baseline that existing summary and slim views and permit an immediate uniform hold. Historical o25's 36 calls are observed expenditure, not a justified estimate of what competent current practice must spend. If the coordinator can already route the assignment in one brief interaction, the marginal benefit is that interaction minus deterministic-screen setup and exception review, not all historical calls. A provisional YES alone cannot rule out an investigated ending or an alternative held current witness.

## Dominant supported mechanisms and alternative hypotheses

1. **Source-availability conditions known in dossiers did not prevent production assignment.** o25 is the cleanest retained example. Replace the launch with an existing source-bound dispatch hold and recovery proposal. Reject a broad rule if a current predicate is optional or an alternative held witness makes the case eligible; a provisional YES label alone must not become a universal hold.
2. **Declared-mandatory source checks did not cover producer-selected evidence.** o27 later failed custody for three reviewed claims. PR139 addresses selected-source guards, with an unapplied caller patch. Prove the actual caller uses it before crediting prevention.
3. **Broad input/context change forces re-prepare after valuable work.** The coordinator log records owner-ruling changes and chained completions invalidating correction packets; re-preparation preserved old sheets. This is observed restart work, but absent command traces do not identify an independently avoidable legal task. Selective invalidation would require tracing the actual field dependence and retaining refusal on meaningful changes.
4. **Independent source/legal examination is real work.** Lind's receipts reduced offset scripts but B used 279 calls versus A270; source/legal reading remained. Do not treat this as avoidable hash-script cost or deploy the failed default.
5. **Shared research already exists.** Apollo/NRA workers, shared-research-production and Valla provide shared premises. Many applications do not prove duplicated source examination. Existing NRA shared memo reached only two eligible of fourteen isolated applications; original/custody and scope exceptions dominated.
