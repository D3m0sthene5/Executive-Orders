# Measurement limits

The GitHub pilot's 24 case attempts are offline prerequisite investigations. They do not measure complete legal production or independent review. Machine timing is a lower bound on executed software work; active agent effort is unmeasured in all 170 phase/shared-event entries. Token values and cash expenditure remain unavailable. Zero observed model API calls does not imply zero coordinator cost.

No new external acquisition was attempted. A zero sampled access-stop count only means no matched explicit access failure was found in the consumed ladder records. It does not establish that access is resolved across the inventory. Unlocated originals, ending instruments, current predicates and review dependencies remain open. Historical census recovery beyond the 14,972 identities is incompletely bounded.

All 24 sampled cases remain blocked on prerequisites. No completion total, confidence interval or date is supported. The scenario formula in UNCERTAINTY.json is conditional on unmeasured per-cell completion costs, future shared costs, access and independent review; it supplies no calibrated numeric scenario. The existing EFFORT_NOTES model is preserved and is not relabeled survey evidence.

Both historical accepted replay arms use EO12720. Their matches are a software regression on one correlated historical case, not two independent confirmations or prospective legal validation. The prospective pilot verifies no-intervention residuals; causal effects of hypothetical prerequisite acquisition remain untested.

LOCAL_VALIDATION.json records three additional executions of the same 24 machine gap probes, including the initial post-attempt Junto integration failure. They are engineering checks, not 72 additional representative observations. Their measured work is preserved separately. GitHub reruns also remain separate run receipts; none should be pooled as independent cases.

The untouched Llull test suite on this main snapshot has one stale Y2 pool-count assertion: expected2,063, actual2,060. Its other21 tests pass with source reports materialized. NEYMAN uses Llull's actual readers and forecast/scoring functions, with no changes to Llull or its scores.
