# Continuous-run protocol (all workflows, from 2026-10-20)
Repo /home/user/Executive-Orders, branch claude/junto-1727. Several workflows run at once: touch only your own paths.
1. Before any production, register forecasts with `python3 -I jobs/llull/llull.py forecast ...` (run `census` on your pool first; add a pool to jobs/llull/ledger/pools.json if needed; read `premortem` for your plan). Then preregister by committing ONLY the ledger: `git add jobs/llull/ledger/ && git commit -m "Llull: preregister <workflow> forecasts"` (retry if index.lock exists; never push; never commit anything else).
2. Producers follow AGENTS.md research procedure and jobs/claim-kit/AGENT_PROTOCOL.md. Reviews use the Mountweazel recommendation: an INDEPENDENT Opus reviewer with access to the held source texts, plus an explicit D6 step ("was any later event that ended or changed this clause removed or ignored?"), trying to refute each item.
3. Probe before scaling: a random probe batch first; scale only if it beats the forecast's p50 or a pre-stated gate; stop that line after 2 failed probes.
4. Guardrails: never change the codebook; AI statuses are hypotheses and are never adopted into DECIDED_CASE_COMPLETENESS_RECONCILED.csv; certified count stays 0; no tier auto-promotion; request sources only via research/readiness/FETCH_QUEUE.jsonl (pushing it triggers the fetch job).
5. Record outcomes in Llull (`outcome`) when measured. Return reports as text (subagents may not write REPORT files); keep final answers short.
6. PLANTED CONTROLS (fix, 2026-10-20): Rastell and Lamm gates failed because no agent ever inserted plants. A gate may require plant catches ONLY if the workflow script has an explicit PLANTER agent step between producer and reviewer. Scouts: do not write plant conditions into a gate unless told a planter step exists. The planter writes plants into the review packet and the key only to <scratch>/plant_keys/, never into research/ or jobs/; a tally step scores and removes them.
7. PLANTS LIVE ONLY IN SCRATCH (2026-10-20): the auto-mode classifier denies writing defective records into in-repo packets (research/excavator/...). Do NOT retry or work around that denial. A planter must copy the review packet to <scratch>/review_copy/<batch>/ and plant there; the reviewer reviews that scratch copy; keys go to <scratch>/plant_keys/. If no plant key exists for a batch, the batch is "unscored for plants" — NOT void; report it plainly.
8. GATES IN CODE (2026-10-20): every probe gate must be enforced in the workflow script itself (Sinclair ran all batches despite a failed gate because only the scout wrote it down).
9. PUSH DISCIPLINE: the coordinator never pushes while a "Run jobs" run is in progress on the branch (a push makes its results commit fail). Batch commits locally; push once when Actions is idle; then wait for the results commit.
10. Cost cap set by the owner: $1,000/day of token value. Keep 3 workflows running. Hand off to a fresh coordinator session (Revere) when coordinator context passes ~400k.
