## Changes to the existing tools

| Tool | Repair and resulting behavior |
| --- | --- |
| **Panizzi** | One shared acquisition-request contract validates before queue append and before execution, retains original requests and correction provenance, separates compound tasks, and leaves unidentified ending sources unresolved. Every carried source receipt is revalidated, including receipts outside a bounded selection. Invalid receipts and their original text are quarantined. Document text, report records, finding aids and custody evidence have explicit tiers. |

| **Lamm** | Clause preparation distinguishes deadlines, performance commands, recurring duties, contingent endings, sunsets, extensions, renewals and savings questions. These features generate research obligations rather than legal rulings. Source-blocked work records its dossier, validated requests, route fingerprint and material source results; unchanged work defers, while relevant changes reopen it. Failed attempts are retained. |
| **Hamilton** | Partial transcript windows no longer inherit an entire session valuation. Absolute allocation requires independently reported complete session-category totals. Cache TTL, absent fields, streaming updates and interleaved agents remain explicit; overlapping diagnostics are not summed. Cash charges, reported API token value and approximate attribution remain distinct. |
| **Mountweazel** | Strict credit requires the material planted issue at the affected clause; missing-event plants also require event identity. An EO-number match or unrelated criticism earns no credit. Manual adjudication retains provenance separately. Missing plants are unscored; real flags remain unadjudicated unless resolved; instructed blinding is distinguished from verified technical isolation. |
| **Polya** | Outputs pin the actual consumed input bytes, detect changes during a calculation and refuse an incomplete required dossier population. Cross-frame reach has a deduplicated union. Remaining prerequisites and hypothetical completion potential are explicit; one blocker category may contain several research actions. Reach is not measured yield or a readiness change. |
| **Llull** | Only verifiably prospective, unchanged forecast records enter calibration. Retrospective and unchecked records are separate; related quantities are grouped by experiment. Outcome and base-rate corrections append without rewriting forecasts or prior results. Untested gates have no numeric outcome. Coverage screens are heuristics, not proven ceilings. |
| **Junto** | Missing or inadequate quality cannot earn verified-savings credit. Comparable workload, units, receipts, quality coverage and complete cost declarations are required. Both arms and overhead enter cost accounting; duplicate/overlapping receipts cannot generate duplicate credit. Explicitly supplied ideas and prospectively registered tests have separate paths, attribution, sample pins, budgets and stop conditions. |
| **Lambertini** | Continuation now calls the executable gate before selecting new work. The historical one-plant observation cannot satisfy the registered two-of-three requirement. Exact-claim source audits withhold completeness while owners resolve the substantive premise. Progress counts retain unresolved, rejected and unreviewed work. |
